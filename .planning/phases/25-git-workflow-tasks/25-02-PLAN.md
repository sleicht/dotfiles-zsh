  <action>
Create `executable_cleanup` in the chezmoi source git task directory.

The script must:
1. Run `git fetch --prune --all` to update remote tracking branches
2. Detect main branch name via `git symbolic-ref refs/remotes/origin/HEAD` (fallback to "main")
3. List merged branches via `git branch --merged $MAIN_BRANCH`
4. Exclude protected branches: current branch (*), main, master, develop
5. If no merged branches found, report and exit 0
6. Display list of branches to delete
7. Require explicit confirmation (y/N) before deletion
8. Delete using `git branch -d` (safe delete, not -D force)
9. Report each deletion with success/failure

Use #MISE directives: description="Prune merged local branches" (no alias — less frequent use)

Use #MISE directives: description="Create pull request via gh CLI" (no alias — less frequent use)
