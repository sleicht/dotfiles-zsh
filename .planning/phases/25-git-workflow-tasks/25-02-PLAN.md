<task type="auto">
  <name>Task 2: Implement git:pr remote-aware pull/merge request task</name>
  <files>private_dot_config/mise/tasks/git/executable_pr</files>
  <action>
Create `executable_pr` in the chezmoi source git task directory.

The script must:
1. Detect platform from origin remote URL: `github.com` → gh, `*gitlab*` → glab (catches gitlab.com, gitlab.client.ch, any self-hosted with "gitlab" in hostname). Fallback: fzf prompt to select platform manually for custom hostnames
2. Validate detected CLI is authenticated (`$CLI auth status`)
3. Reject if on main/master branch
4. Check for upstream tracking branch — offer to push with `-u` if missing
5. Extract Jira ticket from branch name if matching `feature/([A-Z]+-[0-9]+)` pattern, otherwise prompt
6. Prompt for PR/MR title (will be prefixed with `$TICKET:`) — use "MR" terminology for GitLab, "PR" for GitHub
7. Prompt for description (multi-line via `cat`, Ctrl-D to finish)
8. Show preview of title and body, confirm (Y/n)
9. Execute platform-specific create command:
   - GitHub: `gh pr create --title "$PR_TITLE" --body "$PR_BODY"`
   - GitLab: `glab mr create --title "$PR_TITLE" --description "$PR_BODY"`

Use #MISE directives: description="Create pull/merge request via gh/glab CLI" (no alias — less frequent use)
Use `set -euo pipefail`. All errors to stderr.

Reference the research code example in 25-RESEARCH.md "GIT-04: Pull/Merge Request Task (Remote-Aware)" section — use that implementation directly.
  </action>
  <verify>
Run `chezmoi apply` then verify:
- `mise tasks | grep git:pr` shows task with description
- File at `~/.config/mise/tasks/git/pr` is executable
- Script contains remote URL detection (`git remote get-url origin`)
- Script dispatches to `gh pr create` for GitHub and `glab mr create` for GitLab
- Script validates not on main/master before proceeding
  </verify>
  <done>git:pr task deployed, auto-detects GitHub vs GitLab from origin remote, validates CLI auth and branch, extracts Jira ticket from branch name, creates PR/MR with Jira-prefixed title</done>
