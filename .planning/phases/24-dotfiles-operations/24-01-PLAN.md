    **executable_sync (DOT-06)** -- Create new:
    ```bash
    #!/usr/bin/env bash
    #MISE description="Full sync: backup, pull, apply, verify"
    #MISE alias="s"

    set -euo pipefail

    echo "Starting full dotfiles sync workflow..."
    echo ""

    # Step 1: Backup
    echo "[1/4] Creating backup..."
    BACKUP_DIR="${HOME}/.config.backup-$(date +%Y%m%d-%H%M%S)"
    if [[ -d "${HOME}/.config" ]]; then
      cp -r "${HOME}/.config" "$BACKUP_DIR"
      echo "Backup created: $BACKUP_DIR"
    else
      echo "No .config directory to backup"
    fi
    echo ""

    # Step 2: Pull
    echo "[2/4] Pulling latest changes..."
    cd "${HOME}/.local/share/chezmoi"
    git pull --rebase
    echo "Changes pulled"
    echo ""

    # Step 3: Apply
    echo "[3/4] Applying dotfiles..."
    mise run dotfiles:apply
    echo ""

    # Step 4: Verify
    echo "[4/4] Verifying configuration..."
    mise run dotfiles:verify
    echo ""

    echo "Done — sync complete (backup: $BACKUP_DIR)"
    ```
    Note: Uses explicit `mise run` calls (not `depends` field) for correct ordering as documented in research.
