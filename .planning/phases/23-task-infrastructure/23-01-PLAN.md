**File 1: `private_dot_config/mise/tasks/dotfiles/executable_apply`**
- Shebang: `#!/usr/bin/env bash`
- `#MISE description="Apply dotfiles with chezmoi"`
- `#MISE alias="a"`
- Body: `set -euo pipefail` then `chezmoi apply --verbose`
- This proves INFRA-01 (deployment), INFRA-02 (discovery), INFRA-03 (namespacing as dotfiles:apply), INFRA-04 (alias "a")

**File 2: `private_dot_config/mise/tasks/dotfiles/executable_verify`**
- Shebang: `#!/usr/bin/env bash`
- `#MISE description="Verify dotfile configuration"`
- `#MISE sources=["~/.zshrc", "~/.config/mise/config.toml"]`
- `#MISE outputs=["/tmp/dotfiles-verify.timestamp"]`
- Body: `set -euo pipefail`, echo verification message, `touch /tmp/dotfiles-verify.timestamp`
- This proves INFRA-05 (rebuild detection). Phase 24 will replace the stub body with real verification logic.

**File 3: `private_dot_config/mise/tasks/git/executable_commit`**
- Shebang: `#!/usr/bin/env bash`
- `#MISE description="Create conventional commit with Jira prefix"`
- Body: `set -euo pipefail`, echo placeholder message explaining Phase 25 will implement
- This proves INFRA-03 (cross-namespace: git:commit alongside dotfiles:*)

All files use `executable_` prefix so chezmoi deploys them with 0755 permissions. No `.tmpl` suffix needed — these are plain bash, no machine-specific templating.

Anti-patterns to avoid:
- Do NOT use `# MISE` (space after #) — formatters may add it but mise won't recognise it
- Do NOT add `.sh` extension to filenames — mise uses the bare filename as the task name
- Do NOT use Tera templates (arg(), option()) — deprecated, removed in 2026.11.0
